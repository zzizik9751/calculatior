2. 회로별 후강전선관
후강전선관 선정 계산서 — ①CABLE SCHEDULE에 등록된 회로 데이터를 그대로 불러와, 회로별 접지선 사이즈와 전선관 규격을 아래 기준으로 자동 산정합니다.
  • 접지선(F-GV) 선정기준: 상도체(케이블) 공칭단면적 S 기준 — S≤16㎟이면 접지선=S, 16<S≤35㎟이면 접지선=16㎟, S>35㎟이면 접지선=S/2 (다음 표준 사이즈로 올림 적용)
  • 전선관 선정기준: (케이블 단면적 + 접지선 단면적) ÷ 전선관 내부단면적 ≤ 1/3(약 33%, 법적 상한) — 본 계산서는 더 여유있는 권장 충전율 30%를 기본 상한으로 사용합니다(아래 공통설정에서 조정 가능, 최대 33%).
  • 후강전선관 규격은 16·22·28·36·42·54·70·82·92·104mm이며, 호칭(mm)을 안지름으로 보아 내부단면적 π/4×d²을 계산에 사용합니다. 필요단면적이 104mm 전선관의 30% 충전 한도를 넘으면 "선정불가"로 표시합니다(더 큰 규격이 없으므로 전선관을 분할하거나 충전율 재검토가 필요합니다).
  • 전선관 1개에 해당 회로의 케이블 전체 가닥(수량 EA)과 접지선 1가닥을 함께 수용합니다 — 총 단면적 = 케이블 1선 단면적 × 수량(EA) + 접지선 단면적(예: 573×4+314=2,606㎟)으로 계산하고, 이 총 단면적을 기준으로 전선관 1개를 선정합니다.
  • 케이블 1건은 종류·규격(사이즈)·심수(CORE)·수량(EA)이 한 세트입니다.

3. 지중전선관(ELP) 선정
지중전선관(ELP) 선정 계산서 — ③후강전선관 선정과 달리, 지중매설 구간은 여러 회로를 전선관 1개에 함께 수용하는 경우를 계산합니다. 아래에서 "지중전선관 구간"을 하나 만들고, 그 안에 ①CABLE SCHEDULE에 등록된 회로(C.NO)를 필요한 만큼 추가하면 됩니다.
  • 접지선(F-GV) 선정기준은 ③후강전선관 선정과 동일합니다 — 회로마다 개별 접지선 1가닥을 포함합니다.
  • 전선관 선정기준: (그 구간에 포함된 모든 회로의 케이블 합계 단면적 + 각 회로 접지선 단면적의 합) ÷ 전선관 내부단면적 ≤ 1/3(약 33%, 법적 상한). 본 계산서는 더 여유있는 권장 충전율 30%를 기본 상한으로 사용합니다(아래 공통설정에서 조정 가능, 최대 33%).
  • ELP(지중매설용 파상형 전선관) 규격은 호칭(mm)을 안지름으로 보아 30·40·50·65·80·100·125·150·175·200mm이며, 필요단면적이 200mm 전선관의 충전 한도를 넘으면 "선정불가"로 표시합니다(전선관을 분할하거나 회로 구성을 재검토해야 합니다).

4. 적용기준
1. 관련 규정 — KEC 232.41 케이블트레이공사

한국전기설비규정(KEC) 232.41(저압 옥내배선의 케이블트레이공사)은 트레이의 시설방법 — 고·저압 케이블 분리, 방화구획 관통부 처리, 트레이 상호 접속 및 접지, 금속제 트레이의 전기적 연속성, 트레이 종류(사다리형·통풍트러프형·통풍채널형·바닥밀폐형) — 를 규정합니다. 트레이 폭(규격) 자체를 계산하는 상세 산정식은 KEC 조문에 직접 포함되어 있지 않으며, 종전에는 「전기설비기술기준의 판단기준」 제213조의2 및 「내선규정」 1445-6절의 별표에서 다심/단심 케이블의 굵기 구간별로 상이한 4~5가지 산정식을 규정해 왔습니다.

2. 산정방식 변경 — "점유면적·폭 이원기준" → "폭 단일기준"
구분구(舊) 방식 — 내선규정 1445-6 계열현행 실무(본 계산서) — KEC 이후 간이화
판정 기준점유면적(㎟, 충전율%) + 폭(mm) 이원 병행. 케이블 종류(다심/단심)·굵기 구간(120㎟, 500㎟)마다 서로 다른 산식 적용폭(mm) 단일기준. 모든 케이블을 완성품 외경(OD) 합산 → 여유율 → 표준 폭 계열 올림

3. 계산식 (② 탭에 적용된 로직)
① 케이블 1가닥의 폭 기여량 = 완성품 외경 OD(mm)
② 회로별 폭 기여량 = OD × 병렬 회선수(LINE) × 동일사양 수량(EA)
③ 트레이 소요폭(합계) ΣW = Σ(회로별 폭 기여량)
④ 필요폭 = ΣW × 여유율(K) — 기본값 K = 1.1(10% 여유), 현장 조건에 따라 사용자가 조정 가능
⑤ 선정폭 = 표준 트레이 폭 계열 중 "필요폭 이상"이 되는 최소 규격 (올림)
⑥ 참고 점유율(정보용) = ΣW(여유율 미적용) ÷ 선정폭 × 100% — 판정에는 사용하지 않으며 참고 지표로만 표시
단심 케이블은 실제로는 삼각(또는 사각) 배열로 포설하더라도, 트레이 폭 산정 시에는 관례에 따라 1열 배치(외경을 나란히 합산)로 계산합니다.
4. 표준 폭 계열 및 데이터 출처

표준 폭 계열은 실무에서 가장 널리 쓰이는 6종(150/200/400/600/800/1000mm)을 기본값으로 제시합니다. 케이블트레이 규격 자체는 100/150/200/300/400/500/600/700/750/800/900/1000mm까지 다양하게 존재하며(⑤CABLE SPEC 탭의 "케이블트레이 단위중량" 표 참조), 현장·발주처 표준에 맞게 ②탭 상단 설정에서 폭 계열을 자유롭게 추가·수정할 수 있습니다. 케이블 외경(OD)·단면적 데이터는 ⑤CABLE SPEC 탭의 값을 그대로 사용합니다.

6. 제어·신호케이블 트레이 수용률에 대한 참고
KEC 232.41의 단층 포설 규정은 전력용·전등용 다심케이블에 적용되며, KEC에서는 제어용 및 신호용 케이블의 트레이 시설방법을 별도로 규정하고 있지 않다.
따라서 제어·신호케이블의 트레이 수용률은 별도의 설계기준 또는 설계조건에 따라 결정할 수 있으며, 기존 기준에서 적용해 온 '케이블 총 단면적이 트레이 내부 단면적의 50% 이하' 등의 기준을 설계기준으로 채택할 수 있다. (전기설비기술기준의 판단기준 제194조(케이블트레이공사) 참조)
5. CABLE SPEC
수치는 외경은 가온전선 0.6/1kV NFR-8(1심 실측 카탈로그), 중량은 HF-CO 적용. 2~4심 외경은 아직 NFR-8 실측 자료가 없어 참고치를 사용합니다. 도체경·절연두께·시스두께로부터 완성품 외경(OD)을 산출하고, OD로부터 단면적(π/4×OD²)을 계산한 값입니다. 계산기 탭의 케이블 외경 자동조회는 이 표의 값을 그대로 사용합니다.
데이터 범위 안내 — 저압 케이블은 HFCO·F-FR-8 구분 없이 XLPE 하나로 통일했습니다(치수는 HFCO(=F-CV) 실측치 기준, 1~4심). 다심(2~4심)은 실사용 범위인 70㎟까지만 수록합니다. HFIX 등은 참조 엑셀에 치수 데이터가 없어 포함하지 않았으며, 계산기 탭에서 "직접입력"으로 사용해야 합니다. 표 아래쪽의 F-GV(접지용 비닐절연전선)는 ②/①탭의 케이블 선택 목록에는 노출되지 않으며, ③후강전선관 선정·④지중전선관 선정 탭의 접지선 단면적 조회 전용으로만 사용됩니다.
단위중량(kg/km) 안내 — 제조사 카탈로그 실측 자료(114개 조합, XLPE 1~4심 + F-GV 1심)를 반영했습니다. 트레이 계산서(②탭)의 kg/m 자동입력·합계에도 이 값이 그대로 연동됩니다.

방법 3) JSON 배열로 붙여넣기 — 예: [{"cno":"06L","use":"세대부하","from":"1065호 M","to":"전기실","type":"XLPE","core":1,"size":240,"line":4}] (키는 cno/use/from/to/type/core/size/line 또는 한글 열이름 모두 인식)
종류가 XLPE DB와 일치하지 않거나 사이즈가 DB에 없으면 자동으로 "직접입력"으로 처리되며, 이런 행은 미리보기에서 표시됩니다.
